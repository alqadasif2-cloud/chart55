# شارت - cchart | MetaTrader 5 Windows Desktop Edition

تطبيق شارت احترافي متكامل لنظام التشغيل **Windows 10/11 64-bit** يتصل مباشرة بمنصة **MetaTrader 5** المثبتة على جهاز الكمبيوتر لجلب كافة البيانات التاريخية والأسعار الحية دون الحاجة إلى أي مفاتيح API خارجية.

---

## 🌟 مميزات الإصدار الخاص بنظام ويندوز و MetaTrader 5

1. **اتصال مباشر وتلقائي بـ MT5**:
   - لا حاجة لكتابة اسم المستخدم أو كلمة المرور داخل التطبيق.
   - يتصل التطبيق فوراً وبأمان بالجلسة المفتوحة مسبقاً داخل برنامج MetaTrader 5 (`mt5.initialize()`).
2. **بدون مفاتيح API خارجية**:
   - كافة الشموع التاريخية والأسعار الحية والتكات تؤخذ من سيرفر الوسيط المالي (Broker) عبر MT5.
3. **دعم كامل لجميع الرموز واللواحق الخاصة بالوسطاء (Broker Suffixes)**:
   - يتعرف بذكاء على `XAUUSD`, `XAUUSDm`, `XAUUSD.`, `GOLD`, `EURUSD`, `EURUSD.pro`, `BTCUSD` وغيرها.
4. **أمان تام وقراءة حصرية (Read-Only Safety)**:
   - التطبيق مخصص للتحليل الفني وعرض البيانات التاريخية فقط.
   - **لا يقوم بتنفيذ أي صفقات** ولا يطلب صلاحيات تداول (`NO order_send`).
5. **مستقل تماماً عن كود أندرويد**:
   - لا يعتمد على واجهات أندرويد البرمجية أو إعداداتها.

---

## 📋 المتطلبات الأساسية (Prerequisites)

1. نظام تشغيل **Windows 10 أو Windows 11 (64-bit)**.
2. برنامج **MetaTrader 5** مثبت ومسجل الدخول لحسابك التداولي (تجريبي أو حقيقي).
3. بيئة **Python 3.11 (64-bit)**:
   - المسار المهيأ: `C:\Users\user\AppData\Local\Programs\Python\Python311\python.exe`

---

## 🚀 طريقة التشغيل السريعة (Quick Start)

1. افتح برنامج **MetaTrader 5** على جهازك وسجل الدخول لحسابك.
2. انقر نقراً مزدوجاً على الملف:
   ```cmd
   START_WINDOWS.bat
   ```
3. ستفتح نافذة الأوامر وتقوم بالتحقق من بايثون 3.11 والحزم، ثم تشغيل خادم البريدج وفتح نافذة سطح المكتب المستقلة.

---

## 🛠️ بناء ملف التشغيل المستقل (Build Standalone EXE)

انقر نقراً مزدوجاً على ملف:
```cmd
BUILD_WINDOWS_EXE.bat
```
أو عبر GitHub Actions عبر تشغيل سير العمل:
**Build Windows Desktop App (MetaTrader 5 Edition)**
لتحميل ملف `cchart_mt5_windows_x64.zip` مباشرة.
