# الذهب والفضة — شارتات XAU/USD و XAG/USD

تطبيق أندرويد (Kotlin + Jetpack Compose) يعرض أسعار الذهب والفضة وشارت شموع حيّ من Twelve Data.

## الميزات
- سعر الذهب (XAU/USD) والفضة (XAG/USD) مع التغير والافتتاح والأعلى والأدنى
- شارت شموع يابانية مع اسحب لعرض O/H/L/C لكل شمعة
- فواصل: 5د، 15د، ساعة، 4س، يوم + متوسط متحرك SMA 20
- تحديث تلقائي كل دقيقة (مع تخزين مؤقت لتوفير حد الطلبات)
- واجهة عربية RTL ووضع داكن

## بناء APK من GitHub
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد (يجب أن يكون `.github` في الجذر).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يعمل تلقائياً عند الدفع).
3. بعد النجاح نزّل **GoldSilver-debug-apk** من قسم Artifacts، فك الضغط ثم ثبّت `app-debug.apk`.

## مفتاح API
- أسهل طريقة: افتح التطبيق، سيطلب المفتاح تلقائياً (أو زر ⚙ المفتاح)، والصقه واحفظ.
- بديل: أضف سر المستودع `TWELVE_DATA_KEY` في Settings ← Secrets ← Actions ليُدمج وقت البناء.
- لا تضع المفتاح داخل الكود إن كان المستودع عاماً.

## ملاحظات
- الخطة المجانية: 8 طلبات/دقيقة و800/يوم. كل تحديث يستهلك طلبين.
- إن ظهر خطأ أن الرمز غير متاح في خطتك، فهذا قيد من Twelve Data على الخطة وليس من التطبيق.
